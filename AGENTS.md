# AGENTS.md

`ikigai-conformance` is what "done" means for an ikigai module, as one test: it walks a kernel's
endpoints and reports every violation of the module recipe at once.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  pages, terminal text (here, above all, the report).
- Security reports go through [private vulnerability
  reporting](https://github.com/ikigai-rs/ikigai-conformance/security/advisories/new), never a
  public issue.
- Use American spelling (behavior, color, labeled, artifact).
